New game now asks how long the game is (hours and minutes, or just minutes). Recording starts as
soon as the game is created, with no phone or tablet needed, and stops by itself when the time is
up. Staff can Add time to a game while it records (up to 6 hours in all), and the court's device
shows a "5 minutes left" notice near the end.

## Dev notes

- back/: run `npm run db:migrate` — `023_session_added_minutes.sql` adds `recording_sessions.addedMinutes`.
- back/: `POST /api/v1/admin/sessions` with `startNow` + `durationMinutes` now creates the game as
  `Recording` at once. New `POST /api/v1/admin/sessions/:sessionId/extend` `{ minutes }` (`clips`
  write): only while recording, at most 360 minutes in all, payment untouched.
- back/: the court-only (open game, CR-005) create still works for older clients; Admin no longer sends it.
- front/: New game has a Game time (default 1 h, 5 min – 3 h); Sessions list and details show the
  stop time and time added, with Add time; the "Waiting for a device" card is now "Ending soon".
- app/: JavaScript only (over-the-air update, no new build) — "5 minutes left" notice on the
  session screen; demo mode plays a 1-hour game near its end.
- edge/: no recorder box update.
- Staff change how they work: recording starts on Create game, not when the device pairs, and a
  game created by mistake can't be cancelled (End it).
